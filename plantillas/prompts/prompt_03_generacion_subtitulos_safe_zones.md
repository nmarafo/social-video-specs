# 💬 Módulo 03: Generación de Subtítulos Dinámicos en Zonas Seguras

Prompt para generar fragmentos de subtítulos optimizados para lectura veloz sin colisionar con la interfaz de usuario.

---

```markdown
Actúa como un Especialista en Tipografía Cinética y Subtitulado para Formatos Cortos. Convierte el siguiente texto transcripto en un esquema de subtítulos de alta retención (*micro-chunking*):

TRANSCRIPCIÓN:
[Pega aquí el texto hablado del vídeo]

PLATAFORMA OBJETIVO:
[Instagram Reels / TikTok / YouTube Shorts]

REGLAS ESTRICTAS DE SALIDA:
1. Divide el texto en bloques de 1 a 3 palabras por pantalla (nunca más de 4 palabras).
2. Marca en **[COLOR AMARILLO]** o **[VERDE]** la palabra clave o de mayor impacto emocional de cada bloque.
3. Especifica las coordenadas sugeridas de renderizado en base a la zona segura de la plataforma (por defecto centrado en Y: 1150 px en lienzo 1080×1920).
4. Genera el bloque con formato de tiempo estimado o salida compatible con archivo `.srt` si se solicita.
```
