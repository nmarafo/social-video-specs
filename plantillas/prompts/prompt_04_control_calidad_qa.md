# 🔍 Módulo 04: Control de Calidad (QA) y Verificación Técnica Pre-Render

Prompt para someter cualquier proyecto o exportación audiovisual a una auditoría técnica implacable.

---

```markdown
Actúa como el Director de Control de Calidad de una agencia de producción audiovisual. Audita los siguientes datos de un vídeo listo para exportar o publicar:

PARÁMETROS DE EXPORTACIÓN:
- Plataforma de destino: [Ej. Instagram Reels / TikTok / YouTube]
- Resolución y aspecto: [Ej. 1080×1920, 9:16]
- Framerate: [Ej. 30 fps]
- Códec y Perfil: [Ej. H.264 High Profile]
- Bitrate configurado: [Ej. 14 Mbps VBR]
- Nivel de audio estimado: [Ej. -14 LUFS, pico a -1.0 dBTP]
- Posición de subtítulos: [Ej. Centrados abajo a 200px del borde]

AUDITORÍA EXIGIDA:
1. Veredicto: [APROBADO / RECHAZADO CON OBSERVACIONES].
2. Análisis de riesgos de interfaz: ¿Existe riesgo de colisión con botones o cajas de texto de la red social?
3. Análisis de transcodificación: ¿El bitrate provocará compresión agresiva por parte del algoritmo?
4. Comprobación de audio: ¿El volumen cumple con la normalización de sonoridad estándar?
5. Lista de correcciones indispensables antes de renderizar.
```
