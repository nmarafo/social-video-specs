# 📌 Plataforma: Pinterest (Especificaciones Técnicas OKF)

Pinterest es un motor de descubrimiento visual donde el vídeo (*Video Pins* e *Idea Pins*) tiene un ciclo de vida mucho más duradero (semanas y meses) que en plataformas efímeras como TikTok o Instagram.
