# 👥 Plataforma: Facebook (Especificaciones Técnicas OKF)

Facebook sigue siendo una de las plataformas de mayor consumo de vídeo a nivel global, con una audiencia masiva tanto en dispositivos móviles como en navegadores de escritorio. El vídeo en Facebook abarca desde Facebook Reels hasta vídeos horizontales extensos en Facebook Watch y grupos.
