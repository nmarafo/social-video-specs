# ⏱️ Módulo 02: Ritmo, Estructura Narrativa y Storyboarding de Retención

Prompt para estructurar el guion de edición con cambios de plano, ganchos visuales y micro-retención.

---

```markdown
Actúa como un Diseñador de Retención Audiovisual (*Retention Editor*). A partir del siguiente guion o idea de vídeo, genera la escaleta de edición segundo a segundo:

GUION O IDEA BASE:
[Pega aquí el texto o resumen del vídeo]

DURACIÓN OBJETIVO:
[Ejemplo: 30 segundos / 60 segundos]

ESTRUCTURA EXIGIDA:
1. Segundo 0.0 a 2.5 (EL GANCHO): Acción visual inmediata + frase detonante de curiosidad. Sin presentaciones ni saludos.
2. Segundo 2.5 a 10.0 (EL BUCLE DE RETENCIÓN): Planteamiento del conflicto o promesa con cambio de plano o B-roll dinámico.
3. Cuerpo central: Pacing rápido con cortes cada 2.5 a 3.5 segundos (zoom in, corte a plano medio, texto cinético, SFX swoosh/pop).
4. Cierre y Bucle (Loop): Frase final que enlaza de manera natural con el gancho inicial para fomentar reproducciones infinitas.

FORMATO DE SALIDA:
Entrega una tabla con columnas: [Tiempo (Segundos) | Frase Hablada | Visual / B-Roll | Efecto de Sonido (SFX) | Texto en Pantalla].
```
